## TP1: Simple & Multiple Regression

Implementation of regression models using **scikit-learn** to predict salaries and startup profits.

### Summary
- **Simple Regression**: Predicted salaries using `Salary_Data.csv`. Includes data splitting, model training, and visualization.
- **Multiple Regression**: Predicted profits using `50_Startups.csv`. Includes **One-Hot Encoding** for categorical data and **RFE** for feature selection.
- **Evaluation**: Used **R² score** and **RMSE** to measure performance.

### Key Concepts
- Linear & Multiple Regression
- Categorical Data Encoding
- Recursive Feature Elimination (RFE)
- Model evaluation metrics

### Tools
- **Python 3**
- **Libraries**: Pandas, NumPy, Matplotlib, scikit-learn

### How to Run
```bash
pip install numpy pandas matplotlib scikit-learn
python "regression_lineaire_simple.py"
python "regression_lineaire_multiple.py"
```
