# TD01 — Data Analysis: Principal Component Analysis (PCA)

This folder contains the practical resolution of **TD N°1**, focusing on the mathematical foundations of Principal Component Analysis (PCA/ACP).

## Project Overview

The R script acts as a solver for **Exercise 1**, programmatically calculating the following steps:

1.  **Standardization**: Centering and reducing variables to handle different scales ($Z = \frac{X - \mu}{\sigma}$).
2.  **Matrices**: Computing the Variance-Covariance matrix ($V$) and the Correlation matrix ($R$).
3.  **Eigen Decomposition**: Diagonalizing the matrix to find Eigenvalues ($\lambda$) and Eigenvectors (the principal components).
4.  **Inertia**: Calculating the percentage of variance explained by each axis.
