# R Initiation Practical (TP 1)

This repository contains a documented R script based on a university practical session (TP 1) for an introductory course on R.

The script serves as a hands-on guide to the fundamental concepts and commands in the R programming language.

## Features

The script covers the following core topics:

* **Section 1: First Steps in R**
  * Basic arithmetic operations.
  * Vector creation, concatenation, and element-wise operations.
  * Vector repetition using `rep()`.

* **Section 2: Matrices**
  * Creating matrices using `dim()` and `matrix()`.
  * Matrix transpose (`t()`).
  * Element-wise (`*`) vs. matrix (`%*%`) multiplication.

* **Section 3: Plotting**
  * Creating a basic scatter plot with `plot()`.
  * Customizing plots with titles, labels, and colors.
  * Adding lines (`abline()`) and text (`text()`) to an existing plot.

* **Section 4: Random Simulation**
  * Generating random numbers from various distributions (`rnorm`, `rbinom`, `runif`, etc.).
  * Sampling with and without replacement using `sample()`.

* **Section 5: Empirical Descriptions**
  * Plotting empirical distribution functions.
  * Creating histograms (`hist()`) with density overlays (`curve()`).
  * Generating and comparing boxplots (`boxplot()`).
  * Using QQ-plots (`qqnorm`, `qqline`) to check for normality.

* **Section 6: Reading Data**
  * Loading built-in datasets (`data()`).
  * Accessing data frame columns using `$`.
  * Using `attach()` and `detach()` to manage the search path.
