# TP1: Network Configuration

Just my notes from the networking lab. We learned how to set up IPs manually and do some troubleshooting on Linux.

## What we did
- Found our network card name using `lshw`.
- Configured static IP and Gateway using `ifconfig` and `route` .
- Changed our MAC address (spoofing).
- Used `ping`, `traceroute`, and `netstat` to fix connection issues.
