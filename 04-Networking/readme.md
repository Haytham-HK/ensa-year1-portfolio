### Windows Server Mini-Project

A virtualized client-server infrastructure built with Hyper-V simulating a corporate network:

* **Active Directory:** Domain `ENSA.IACS` with organizational units for students and faculty
* **Group Policy Objects (GPO):** Control Panel restrictions, password policies, desktop standardization
* **Exchange Server:** On-premise email with OWA access
* **DNS and DHCP:** Integrated with Active Directory

## Topics Covered

* Windows Server and Active Directory
* Group Policy management
