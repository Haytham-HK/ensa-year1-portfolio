# 08-Cloud Computing & Virtualisation

This folder contains practical work related to cloud computing and virtualization.

## Contents

| Folder | Description |
| :--- | :--- |
| [TP0 : LocalStack](./TP0%20:%20localstack) | Introduction to AWS services using LocalStack: S3 bucket creation and management via AWS CLI. |
| [TP1 : OpenStack](./TP1%20:%20OpenStack) | OpenStack installation with DevStack, exploring the Horizon dashboard and CLI. |
| [TP2 : OpenStack Cloud VM](./TP2%20:%20OpenStack%20Cloud%20VM) | Creating and managing virtual machines on OpenStack cloud infrastructure. |
| [TP3 : Cinder & Swift](./TP3%20:%20Cinder%20%26%20Swift) | Working with OpenStack storage services: volumes, snapshots, and object storage availability checks. |
| [TP4 : CC&V](./TP4%20:%20CC%26V) | OpenStack Nova practical work: VM lifecycle for AI tasks, Python/ML stack setup, snapshotting, and telemetry availability checks. |
| [mini projet](./mini%20projet) | A machine learning web application (Flask + Scikit-learn) deployed on cloud infrastructure using LocalStack S3 for storage. |

## Topics Covered

* Cloud computing concepts and service models
* Amazon Web Services (AWS) simulation with LocalStack
* S3 object storage management
* OpenStack cloud platform (DevStack, Horizon, CLI)
* Virtual machine provisioning and management
* AI workloads on cloud VMs (TensorFlow, PyTorch basics)
* Snapshot lifecycle and telemetry/monitoring checks
* Deploying Python applications on cloud infrastructure
