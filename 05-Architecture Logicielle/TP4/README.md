# TP4 Microservices Project

## Architecture
The TP4 microservices project is designed to demonstrate the use of microservice architecture principles. Each microservice is responsible for a specific functionality and communicates with other services through APIs, ensuring scalability and maintainability.

## Technologies Used
- **Programming Languages**: Java, JavaScript
- **Frameworks**: Spring Boot for Java microservices, Node.js for JavaScript services
- **Databases**: PostgreSQL for storing relational data, MongoDB for non-relational data
- **Containerization**: Docker for containerizing microservices
- **APIs**: RESTful services for communication between microservices

## How to Use
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Haytham-HK/ensa-year1-portfolio.git
   cd ense-year1-portfolio/05-Architecture Logicielle/TP4
   ```
2. **Setup Environment**:
   - Ensure Docker is installed and running on your machine.
   - Configure environment variables if required.
3. **Build and Run Services**:
   ```bash
   docker-compose up --build
   ```
4. **Access the Services**: 
   - Each service can be accessed via its designated endpoint as specified in the documentation.

## Conclusion
This project provides a clear example of how to architect a microservices-based application using modern technologies. Each component can be developed and deployed independently, facilitating agile development practices.
