# 05-Architecture Logicielle

This folder contains practical work and reports related to software architecture, covering the full progression from monolithic applications to microservices.

## Contents

| Folder | Description |
| :--- | :--- |
| [TP1](./TP1) | Simple monolithic e-commerce application with Spring Boot (products and categories REST API). |
| [TP2](./TP2) | Modular monolith with DTOs, MapStruct, and separate Customer and Order modules. |
| [TP3](./TP3) | Distributed monolithic architecture with Nginx load balancing and service replication. |
| [TP4](./TP4) | Microservices architecture with Spring Cloud: Eureka service discovery, API gateway, and dedicated product and order services. |

## Technologies

* Java (Spring Boot, Spring Data JPA, Spring Cloud)
* Maven
* Nginx (reverse proxy and load balancing)
* Eureka (service discovery)
* REST APIs and DTOs
* MapStruct

## Topics Covered

* Monolithic architecture design and REST API development
* Modular decomposition and separation of concerns
* Distributed systems and load balancing
* Microservices patterns: API gateway, service registry, inter-service communication
