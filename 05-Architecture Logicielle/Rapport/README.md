# Software Architecture Lab Reports

This folder contains a few lab reports I put together for my Software Architecture class. They document my ongoing learning process with different architectural patterns.

## Contents

### [Lab 1: Simple Monolithic E-commerce Application](./TP1.pdf)
- **Goal:** To get familiar with the core concepts of monolithic design and learn my way around Spring Boot and Spring Data JPA.
- **Tech Stack:** Java 17, Spring Boot 3.2.2, Maven, PostgreSQL, and Lombok.
- **Features:** A simple REST API for basic CRUD operations on products and categories.

### [Lab 2: Modular Monolith](./TP2.pdf)
- **Goal:** To explore ways to reduce coupling and make the code a bit easier to maintain by separating different business domains within a single deployment unit.
- **Key Concepts Tried:** Organizing code by feature (modules), using DTOs, exploring automated mapping with MapStruct, and setting up communication between modules.
- **Modules:** Customer, Product, Order, and Category.
