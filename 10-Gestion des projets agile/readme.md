## Project: CampusEco

A web application that allows ENSA students to report environmental issues on campus (energy waste, water leaks, etc.) and receive AI-driven eco-responsible recommendations.

**Tech Stack:** Java (Spring Boot), React.js, PostgreSQL/SQLite

**Methodology:** Scrum with 4 one-week sprints, WIP limits, and a formal Definition of Done.

## Topics Covered

* Scrum framework (sprints, backlog, ceremonies)
* User story writing and prioritization
* Agile project management tools (Taiga / OpenProject)
* Spring Boot REST API development
* Frontend development with React.js
* Continuous integration and iterative delivery
