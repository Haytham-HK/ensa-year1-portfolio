# Campus Eco-Responsable & IA

## Project Overview
An application for ENSA Beni Mellal students to report environmental issues on campus (energy waste, water leaks, etc.) and receive AI-driven suggestions for eco-responsible actions.

This project is developed following the Scrum Agile Methodology over 4 sprints of 1 week each.

## Features
- Issue Reporting: Signal environmental problems with details.
- Dashboard: View and track the status of reported issues.
- Admin/Staff View: Update status (Pending, In Progress, Resolved).
- AI Suggestions: Automated eco-responsible recommendations based on reports.

## Tech Stack  
- Frontend: React.js or Vue.js (Open Source)
- Backend: Node.js (Express) or Django
- Database: PostgreSQL or SQLite
- Agile Tool: Taiga or OpenProject 

## Scrum Team
- Roles: Product Owner (PO) and Scrum Master (SM).
- WIP Limit: Maximum 2 tasks in progress simultaneously.

## Definition of Done (DoD)
A User Story is considered DONE only if it is:
1. Developed
2. Tested
3. Integrated
4. Deployable
5. Validated by the Product Owner
