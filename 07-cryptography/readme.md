# 07-Cryptography

This folder contains practical work related to cryptography, using CrypTool for hands-on exploration of classical and modern cipher algorithms.

## Contents

| Folder | Description |
| :--- | :--- |
| [TP0 : Initiation to CrypTool](./TP0%20:%20Initiation%20to%20cryptool) | Introduction to CrypTool 1 and CrypTool 2: encrypting and analyzing Caesar and Vigenere ciphers. |
| [TP1 : Classical Cipher Algorithms](./TP1%20:%20Algorithmes%20de%20chiffrement%20classiques) | Analysis of classical substitution and transposition ciphers and frequency analysis techniques. |

## Topics Covered

* Classical ciphers: Caesar cipher, Vigenere cipher
* Frequency analysis and cryptanalysis
* Using CrypTool 1 and CrypTool 2 for encryption and analysis
