# Project 03: Hiring Decision Classifier

This project builds a **Decision Tree Classifier** to automate the hiring process. It determines if a candidate should be "HIRED" or remain "UNEMPLOYED" based on their experience and language skills.

## Overview
* **Algorithm**: Decision Tree Classifier (`max_depth=3`).
* **Features**: 
    * Internships (Number of previous internships).
    * English Level (0 = Basic, 1 = Advanced).
* **Target**: Status (HIRED / UNEMPLOYED).
* **Visualization**: Uses `matplotlib` and `sklearn.tree.plot_tree` to visualize the decision logic nodes.

## Files
* `travaile_or_non.ipynb` — The notebook containing the model training and tree visualization code.
* `job_hiring.csv` — The dataset of candidate profiles and their hiring outcomes.
