# TP03 — Python: Kaprekar Numbers

This Python exercice first checks if a single user-provided number is a Kaprekar number. It then automatically runs a search to find and print the first 10 Kaprekar numbers.

A Kaprekar number is a non-negative integer, the representation of whose square can be split into two non-zero parts that add up to the original number.

## Prerequisites
- Python 3.x installed.
