# TP04 — Python: Data Structures Exercices

This folder contains a collection of Python exercices focused on built-in data structures. All scripts, comments, and output have been translated into English .

## Files (Exercices)
- `01_string_methods.py` — Demonstrates common string methods (`.title()`, `.count()`, `.swapcase()`).
- `02_list_basic_methods.py` — Covers list manipulation: `.append()`, `.pop()`, `.sort()`, `min()`, `sum()`, etc.
- `03_tuple_and_set_ops.py` — Shows the immutability of tuples and basic set operations (`.union()`, `.intersection()`).
- `04_list_advanced_methods.py` — More list methods, including `.insert()`, `.remove()`, and user input.
- `05_list_slicing.py` — A set of examples for advanced list slicing (e.g., `[start:stop:step]`).
- `06_text_analyzer.py` — A program that takes user input and performs a simple text analysis (total words, unique words, most frequent word, etc.).
