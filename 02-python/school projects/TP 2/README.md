# TP 2 :

A collection of simple Python scripts and algorithm exercises. Each script is a standalone exercice.

## Exercices Included

This repository contains the following projects:

* **`armstrong_number.py`**
  * **What it does:** Checks if a given three-digit number is an Armstrong number (a number that is the sum of the cubes of its own digits).

* **`guess_number.py`**
  * **What it does:** A classic "Guess the Number" game. The script generates a random number between 1 and 100, and you have 10 tries to guess it.

* **`perfect_number.py`**
  * **What it does:** Finds the nearest perfect number (either higher or lower) to a given starting number from the user.

* **`palindromic_number.py`**
  * **What it does:** Checks if a given integer is a palindrome (a number that reads the same backward as forward, like 121).

* **`square_root.py`**
  * **What it does:** Finds the approximate integer square root of a positive number using a binary search (bisection) algorithm.
