#  TP1 - Initiation à Python : Installation et Premiers Pas

Ce dépôt contient le premier travail pratique (TP1) .

L'objectif principal de ce TP est de maîtriser l'installation et la configuration de l'écosystème de développement Python.

---

##  Objectifs Pédagogiques

Ce TP a été conçu pour :
1- Installer un environnement Python fonctionnel via la distribution **Anaconda**.
2- Se familiariser avec l'IDE .
3- Exécuter les premières lignes de code et valider l'installation.
