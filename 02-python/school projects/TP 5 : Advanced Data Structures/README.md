# TP05 — Python: Advanced Data Structures

This folder contains a collection of Python exercices focused on advanced data structures and functional programming concepts. All scripts have been translated into English for a professional portfolio.

## Prerequisites
- Python 3.x installed.

## Files (Exercices)
- `01_functional_methods.py` — Demonstrates functional methods: `filter()`, `map()`, and `reduce()`.
- `02_tuple_methods.py` — Covers tuple methods and operations like `.count()`, `.index()`, `sorted()`, and `max()`.
- `03_set_methods.py` — Shows common set operations: `.add()`, `.remove()`, `.union()`, `.intersection()`, etc.
- `04_dictionary_methods.py` — Covers dictionary methods: `.get()`, `.keys()`, `.values()`, `.pop()`, `.update()`, etc.
