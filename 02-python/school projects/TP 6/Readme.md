# TP06 — Python: Modules, Packages & File I/O

This folder contains a collection of Python exercices focused on modular programming and file manipulation (TXT, JSON, XML). All scripts have been translated into English for a professional portfolio.

## Prerequisites
- Python 3.x installed.

## Files (Exercices)
- `ex1.py` — Demonstrates built-in modules: `math` for calculations and `datetime` for timestamps.
- `ex2.py` — Covers package creation using the custom `geometrie` package to calculate areas.
- `ex3.py` — Shows text file operations: reading student data and writing calculated averages.
- `ex4.py` — Covers JSON manipulation: parsing data structures and updating records.
- `ex5.py` — Demonstrates XML handling: parsing element trees and appending new nodes.

## Files (Data & Packages)
- `geometrie/` — A custom Python package containing the `cercle` and `rectangle` modules.
- `students.txt` — Input text file containing a list of student names and grades used in `ex3.py`.
- `average.txt` — Output text file generated by `ex3.py` containing the calculated class average.
- `data.json` — JSON dataset representing employee records (name, age, position) used in `ex4.py`.
- `students.xml` — XML dataset containing structured student information used in `ex5.py`.
