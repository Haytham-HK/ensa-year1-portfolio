# Introduction to Machine Learning (Scikit-Learn)

This repository contains a collection of four introductory scikit projects implemented in Python. They demonstrate the fundamental concepts of supervised learning: **Regression** (predicting values) and **Classification** (predicting categories).

Each project includes a Jupyter Notebook (`.ipynb`) and a corresponding dataset (`.csv`).

---

##  Project List

### 1. Student Grade Prediction
**Type:** Regression  
**Algorithm:** `LinearRegression`
**Goal**: Predict a student's final grade (0-20) based on the number of hours they studied.

### 2. Titanic Survival Prediction
**Type:** Classification  
**Algorithm:** `LogisticRegression`
**Goal**: Predict whether a passenger survived the Titanic disaster based on socio-economic features.


### 3. Hiring Decision Classifier
**Type:** Classification  
**Algorithm:** `DecisionTreeClassifier`
**Goal**: Automate the hiring process by predicting if a candidate is "HIRED" or "UNEMPLOYED".

### 4. Student Pass/Fail Classifier
**Type:** Classification  
**Algorithm:** `LogisticRegression`
**Goal**: Predict the binary outcome (PASS/FAIL) for a student.
