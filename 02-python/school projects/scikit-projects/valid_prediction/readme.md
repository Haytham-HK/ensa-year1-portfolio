# Project 04: Student Pass/Fail Classifier

This project uses **Logistic Regression** to predict a binary outcome: whether a student will PASS or FAIL a course. Unlike the grade predictor (Project 01), this treats the problem as a classification task.

## Overview
* **Algorithm**: Logistic Regression.
* **Features**: 
    * Grade (Numeric).
    * Absences (Count).
* **Target**: Result (PASS / FAIL).

## Files
* `valid or non.ipynb` — The notebook for training the classifier.
* `student_pass_fail.csv` — The dataset containing student performance records.
