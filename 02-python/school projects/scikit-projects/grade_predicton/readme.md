# Project 01: Student Grade Prediction (Linear Regression)

This project implements a simple **Linear Regression** model to predict a student's grade based on the number of hours they studied. It demonstrates the fundamental concept of predicting a continuous variable.

## Overview
* **Algorithm**: Linear Regression (Supervised Learning).
* **Input Feature**: Study Hours (Numeric).
* **Target Variable**: Grade (Numeric, 0-20).
* **Library**: Scikit-Learn (`sklearn.linear_model.LinearRegression`).

## Files
* `grade_prediction.ipynb` — The Jupyter Notebook containing the training and prediction logic.
* `student_grades.csv` — The dataset with historical study hours and grades.
