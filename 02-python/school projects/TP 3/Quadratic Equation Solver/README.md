# TP03 — Python: Quadratic Equation Solver (ax^2 + bx + c)

This Python exercice solves a quadratic equation (`ax^2 + bx + c = 0`). It takes `a`, `b`, and `c` as input and correctly calculates the solution. It handles all cases, including linear equations (`a=0`) and complex solutions (`delta < 0`).

## Prerequisites
- Python 3.x installed.
