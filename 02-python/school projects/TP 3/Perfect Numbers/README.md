# TP03 — Python: Perfect Numbers

This Python exercice finds the first 4 perfect numbers. A perfect number is a positive integer that is equal to the sum of its proper positive divisors (e.g., 6 = 1 + 2 + 3).

(Note: The script is set to find 4 numbers because the 5th perfect number, 33,550,336, is too large to be found by this method in a reasonable time.)

## Prerequisites
- Python 3.x installed.
