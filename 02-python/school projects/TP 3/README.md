# TP03 — Python: Algorithmic Exercices

This folder contains a collection of Python exercices focused on algorithms, number theory, and problem-solving. Each exercice is separated into its own project with a `main.py` entry point.

## Prerequisites
- Python 3.x installed.

## Files (Exercices)
- `Quadratic_Solver/` — Solves a quadratic equation (`ax^2 + bx + c = 0`) for all real and complex cases.
- `Collatz_Conjecture/` — Implements the `3n+1` problem, calculating the steps to reach 1.
- `Integer_Division/` — Calculates integer division (`a // b`) using only repeated subtraction.
- `Palindrome_Sequence/` — Finds a palindrome by repeatedly adding the sum of its own digits.
- `Custom_Sequence/` — Calculates the *n*-th term of the sequence `F(n) = F(n-1)^2 + F(n-2)^2`.
- `Amicable_Numbers/` — Finds the first 3 pairs of amicable numbers.
- `Kaprekar_Numbers/` — Checks for and finds the first 10 Kaprekar numbers.
- `Perfect_Numbers/` — Finds the first 4 perfect numbers by summing their proper divisors.
