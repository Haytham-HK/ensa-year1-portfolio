# DVD Rental Exercice

This exercice uses the standard PostgreSQL "DVD Rental" sample database to practice a wide variety of DQL queries. The queries cover basic filtering, aggregations, and complex multi-table joins.

## How to install the database 

`createdb -U postgres dvdrental`

`pg_restore -U postgres -d dvdrental -v "/directory/dvdrental`

## Files
- `dvdrental.tar` — The PostgreSQL database backup file.
- `dvdrental_queries.sql` — A single SQL script containing the 20 queries from the exercice, translated into English.
