# TP04 — DQL: Data Query Language (PostgreSQL)

This lab focuses on the Data Query Language (DQL). It provides a series of exercises to practice querying a database using `SELECT` and its most common clauses.

## Prerequisites
- PostgreSQL installed and running.
- A database to work in (e.g., `tp_ecommerce` from the previous TPs).

## Files
- `00_schema_and_data.sql` — Creates the `etudiants` and `filieres` tables and populates them with data.
- `01_queries_basic_filtering.sql` — Contains `SELECT` exercises using `WHERE`, `LIKE`, `IN`, `BETWEEN`, and `IS NULL`.
- `02_queries_aggregation_joins.sql` — Contains `SELECT` exercises using `ORDER BY`, `GROUP BY`, `HAVING`, and `JOIN`.
