# 03-SQL Projects

This folder contains SQL and database-related practical labs and projects, categorized by technology.

## Contents

| Folder | Description |
| :--- | :--- |
| [PSQL](./PSQL) | PostgreSQL labs covering environment setup, DDL, DML, DQL, joins, and a DVD rental exercise. |
| [PL-SQL](./PL-SQL) | Oracle PL/SQL labs covering environment setup, basic scripting, cursors, and exception handling. |
| [F1](./F1) | Formula 1 database schema design and query exercise. |

### PostgreSQL (PSQL)

| Lab | Topics |
| :--- | :--- |
| TP 1 : Environment Preparation | User creation, database setup |
| TP 2 : DDL | CREATE, ALTER, DROP statements |
| TP 3 : DML | INSERT, UPDATE, DELETE statements |
| TP 4 : DQL | SELECT queries, filtering, aggregation, joins |
| TP 5 : SQL Joins | INNER, LEFT, RIGHT, FULL OUTER joins |
| DVD Rental Exercise | Complex queries on a real-world dataset |

### Oracle PL/SQL

| Lab | Topics |
| :--- | :--- |

| TP04 : Exception Handling | Predefined and user-defined exception handling |

## Topics Covered

* Relational database design
