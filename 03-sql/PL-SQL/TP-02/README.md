# TP02 — PL/SQL: Initiation

This lab introduces **PL/SQL** (Procedural Language/Structured Query Language), Oracle's procedural extension to SQL. It covers the structure of PL/SQL blocks, variable declaration, control structures (IF/LOOP), and basic error handling.

## Prerequisites
- **Oracle Database XE** (18c or 21c) installed.
- **SQL Developer** installed and connected to the database.
- **DBMS_OUTPUT** enabled in SQL Developer to see the results.

## How to Run

1.  Open **Oracle SQL Developer**.
2.  Connect to your database (e.g., `system` or your specific user).
3.  **Enable Output**: Go to `View` > `DBMS Output`. In the DBMS Output pane, click the green **+** icon and select your connection.
4.  Open the `tp02.sql` file.
5.  Run the entire script (F5) or highlight specific blocks and run them (Ctrl+Enter).
6.  Check the "Script Output" or "DBMS Output" pane to see the printed messages.
